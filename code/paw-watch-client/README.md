# PawWatch — Next.js Client

Next.js 16 (App Router) frontend for PawWatch Clarksville.

See the [root README](../../README.md) for full setup instructions.

## Quick start

```bash
npm install
npm run dev   # http://localhost:3000
```

Requires the Django API running at `http://localhost:8000`. Configure via `NEXT_PUBLIC_API_URL` in `.env.local`.
